# Spatial Lab · 3D Model Library

- Objaverse（LVIS 分类，Sketchfab CC）
- Poly Haven（CC0 专业摄影测量）
- Khronos glTF-Sample-Assets（glTF 官方样张）
- 本机 AI 生成（TripoSR / SD-Turbo）
